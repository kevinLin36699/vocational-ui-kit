# AI 页面补充

读取实际绑定库的 AI 文档与当前相关源码；以下是运行技能时的核对重点，不替代版本化规范。

- 任务/推荐只预填，用户主动发送后执行；有未发输入时保护原草稿。
- Enter发送、Shift+Enter换行；输入法组字不发送。发送中保留下一条草稿且防重，停止动作与发送分别表达。
- 处理步骤来自真实可公开阶段；模拟明确标识。过程能完成/停止/失败，失败在原消息恢复，重试不重复插入用户问题或真实写入。
- 会话切换隔离草稿、附件、技能与结果；每轮结果及业务自行维护的编辑状态独立，不让旧入口打开新结果。
- 工作区收放保留输入、编辑、布局偏好和合理焦点，不强制抢回用户手动关闭的面板。
- 阅读历史不被新消息拉回；提供回到最新消息。卸载/切换身份后旧回调失效。
- 附件的已选择、已上传、已解析、已核验分开。引用只能来自实际可说明来源；不捏造教师记录、学生成绩或实时教务数据。
- 普通问答、课程创作、学生作业/考试的权限和分栏时点不同，以当前业务契约控制，不能机械套 chat 配方。
- 模拟失败入口只用于演示恢复，不显示真实服务已经修复。AI模拟不要求 API key，也不为验证引入外部付费服务。

生成区域只复用当前库的空容器/插槽，具体内容和编辑器由业务接入；不恢复历史全类型目录或强制统一业务编辑结构。资源类型→对象、技能正文前可移除标签和反馈交互按当前库规范读取，不在技能内复制另一套实现。

## 当前输入组合
- 读取 documents.resource_composer 与 contracts.resource_composer：`/` 或「＋ 资源」菜单先选类型再选对象，端侧目录由业务配置，资源片段保留对象标识。
- 读取 documents.skill_selection：入口短文“技能”，内置／我的页签，选中技能位于正文前，可移除；不覆盖正文、不自动发送。样式复用当前源码中的浅蓝资源入口、浅蓝紫技能入口，不回退到全灰或旧的“添加”文案。
- 教师页读取 documents.teaching_agents 与 contracts.teaching_agents；`agentOptions`／`selectedAgents` 为实际支持的可选参数。无可见“教学关联”标题，短项默认居中、不留勾空位，选中显示蓝底与勾。目录由当前身份与需求决定，其他角色可传 `agentOptions:[]`；演示 ID 不能用于真实调度。
- 选中只改草稿；发送携带 `agents`、资源、技能、附件；运行锁定，停止后可调整下一轮，重试用原轮快照。不同会话分别恢复草稿关联。

## 容器与业务内容
读取 documents.generated_content 与 contracts.workspace。默认 `VocUI.mount(host,'workspace')` 只生成外壳和空插槽。需要业务内容时，用真实支持的 `VocContentWorkspace.getSlot` / `setContent` 挂载现有或本次请求的业务预览／编辑器；`setToolbar` / `setActions` 按需提供。业务状态、权限、版本、保存与审核归页面控制器，不硬编码到技能或通用库。未提供内容时不能标为业务生成成功；有明确业务内容需求时必须实现，不能只交空壳。

## 详细处理记录示例的边界
examples.detailed_process_preview 展示单项折叠卡：阶段标题与状态、查询主题、公开结果摘要、来源和适用范围；支持停止、失败与重试的本地演示。它尚未替换公共 process 组件，也不是所有页面强制模板。仅在需求适用时参考其布局作为局部扩展，不声称存在相应公共参数；不复用示例资料作为真实查询结果，不展示内部推理。
