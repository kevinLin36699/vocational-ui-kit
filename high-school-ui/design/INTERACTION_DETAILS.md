# 交互细节修正 · 2.1.1

用户指出2.1.0存在分页组织松散、树目录没有悬停、图表明细未经整理、日期回显留白过大和多选只显示数量等问题。上一轮的布局与功能检查不能代表设计质量验收。本次保持70个组件、15类组合和既定品牌，直接修正共用实现。

## 公共组件的改动

| 问题 | 处理 | 影响范围 |
| --- | --- | --- |
| 分页分散在三处、只显示页数比例 | 总数在左；每页条数与数字分页在右聚合；页码、省略跨页、上一页/下一页及边界禁用；窄容器分两行 | pagination与table共用一套分页渲染 |
| 树目录缺少可操作反馈 | 完整行悬停、选中浅蓝与侧边指示、层级引导线、文件图标、展开箭头方向；展开和选择分开 | tree以及公共hover规范 |
| 图表像进度条，明细仅原生文本 | 图表显示明确刻度；明细按学院/数量/占比对齐；只保留一个收放指示；筛选后的图、表与摘要一致 | chart、analytics组合 |
| 普通表格首列全部被固定44px | 只给直接包含复选框的列保留窄宽度，其余按内容分配 | 资源、明细及其他无复选框表格 |
| 日期值间距失衡、图标层级混乱 | 340px紧凑范围控件，日历入口在左，等宽数值用YYYY/MM/DD，清空在悬停/聚焦出现 | date所有范围实例；内部ISO与日期行为保持 |
| 多选只在框内显示“已选N项” | 框内可移除标签，默认最多2个，按宽度省略；+N展开全部已选并可移除；下拉多选使用复选标记，避免整片蓝底 | multiselect、树/级联多选 |
| 其他同类问题 | 短控件不再强制大面积空舞台；公共按钮/选择/折叠提供明确hover；原生details统一SVG指示并清除重复标记 | 展示站与相关公共组件 |

## 参数与事件

- multiselect增加`maxTagCount`，正整数，默认2；仍受控件可用宽度限制。保留`options/values/name/disabled`与原有voc:change `{action:'select',value:[id]}`。
- tree-select的multiple模式复用同一框内标签；`maxTagCount`规则相同，仍发出tree-select事件，不混入内部select事件。
- pagination仍接收`total/page/pageSize/pageSizes`，事件`{action:'pagination',value:{page,pageSize}}`；数字页和省略跨页都可操作。table的每页数据、选择范围和导出逻辑保持。
- date只改显示格式和结构。手动输入兼容`YYYY-MM-DD`与`YYYY/MM/DD`；公共date-change事件与表单隐藏值保持`YYYY-MM-DD`。范围校验、禁选和Esc恢复不改变。
- chart的展开状态在筛选时保留，摘要、图形和明细使用同一集合。
